# Controller 与 Router

- `controller` 只负责参数绑定、基础校验、调用 service 和统一响应。
- `router` 只负责路由注册、中间件绑定和分组接线。
- `controller + router` 经常共同出现，但修改一个不代表必须修改另一个。
- Controller 保持线性控制流，不放入数据查询或业务判断。
- 参数绑定、错误响应、成功响应、鉴权和日志方式必须复用项目公共组件。
- Router 沿用现有分组、版本前缀、HTTP 方法、路径命名和中间件顺序。
- 新增或修改路由后检查重复注册、冲突路径以及主入口是否已挂载模块。
- 未命中接入层时，不增加 HTTP 接线改动。
